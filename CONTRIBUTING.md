# Contributing to KUBUILD

Thanks for your interest in contributing. See [CLAUDE.md](CLAUDE.md) and `docs/` for the architecture and the commands (`pnpm install`, `pnpm run test`, `pnpm run typecheck`, `pnpm run lint`), and add a changeset (`pnpm changeset`) for any change to a published package.
