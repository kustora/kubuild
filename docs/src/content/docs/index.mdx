## Package Ecosystem

```
@kubuild/schema  →  @kubuild/core  →  @kubuild/components  →  @kubuild/renderer  →  @kubuild/editor  →  @kubuild/react
```

- **`@kubuild/schema`**: Zod schemas and TypeScript definitions for PageDocument, Nodes, and Bindings.
- **`@kubuild/core`**: Command engine, History (Undo/Redo), Version Migration, and Tree validation.
- **`@kubuild/components`**: Component registry and base component definitions.
- **`@kubuild/renderer`**: Pure recursive React renderer with responsive viewports.
- **`@kubuild/editor`**: Visual canvas, Zustand UI state, and drag-and-drop interaction.
- **`@kubuild/react`**: Unified consumer wrapper ready for production apps.
