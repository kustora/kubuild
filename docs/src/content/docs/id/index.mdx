## Ekosistem Paket KUBUILD

```
@kubuild/schema  →  @kubuild/core  →  @kubuild/components  →  @kubuild/renderer  →  @kubuild/editor  →  @kubuild/react
```

- **`@kubuild/schema`**: Skema Zod dan definisi TypeScript untuk PageDocument, Node, dan Binding.
- **`@kubuild/core`**: Command engine, Riwayat (Undo/Redo), Migrasi Versi, dan Validasi Pohon Komponen.
- **`@kubuild/components`**: Registry komponen dan definisi komponen bawaan.
- **`@kubuild/renderer`**: Renderer React rekursif murni dengan dukungan viewport responsif.
- **`@kubuild/editor`**: Visual canvas, state UI Zustand, dan interaksi drag-and-drop.
- **`@kubuild/react`**: Wrapper gabungan yang siap diintegrasikan pada aplikasi produksi.
