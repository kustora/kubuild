# Editor Visual Tabel & Spreadsheet

KUBUILD menyertakan visual spreadsheet dan data grid studio untuk merancang tabel harga responsif, bagan perbandingan fitur, template invoice, dan data terstruktur tanpa perlu menulis tag `<table>` HTML secara manual.

## Mode Tampilan

Tersedia dalam dua pilihan mode:
- **Mode Docked**: Tersemat langsung di bagian bawah atau samping canvas.
- **Mode Floating Modal**: Jendela spreadsheet melayang yang dapat dipindahkan ke mana saja untuk kemudahan pengeditan tabel multi-kolom yang lebar.

## Fitur Spreadsheet

- **Operasi Baris & Kolom**: Tambah atau hapus baris dan kolom dengan satu klik.
- **Penggabungan Sel (Merge & Unmerge)**: Pilih rentang sel untuk menggabungkannya secara otomatis menggunakan atribut `colspan` dan `rowspan`.
- **Pengaturan Header**: Ubah sel biasa menjadi tag header semantik `<th>`.
- **Format Sel**: Atur perataan teks (horizontal & vertikal), warna background sel, dan garis pembatas (border).
- **Interpolasi Variabel**: Sisipkan variabel dinamis seperti `{{item.price}}` langsung ke dalam sel tabel.
