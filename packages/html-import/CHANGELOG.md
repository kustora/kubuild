# @kubuild/html-import

## 0.1.0

### Minor Changes

- First public release: convert static HTML (or a zipped site) into a KUBUILD `PageDocument` with `importHtml`, `importHtmlToStoraPackage` and `htmlToNodes`. Includes sanitizing, stylesheet cascade and responsive breakpoint mapping, optional Tailwind support and an import report.
