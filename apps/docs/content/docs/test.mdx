## 3. Step-by-Step Installation Workflow

Gunakan `<Steps>` dan `<Step>` untuk menyusun panduan instalasi terstruktur:

<Steps>
  <Step>
    ### 1. Pasang Dependensi Utama
    Pasang package inti builder ke dalam aplikasi Anda.
    
    ```bash
    pnpm add @kubuild/core @kubuild/renderer
    ```
  </Step>

  <Step>
    ### 2. Definisikan Dokumen Stora
    Buat struktur dokumen `.stora` berbasis JSON/Zod.
    
    ```json title="document.stora.json"
    {
      "version": "1.0.0",
      "nodes": []
    }
    ```
  </Step>

  <Step>
    ### 3. Render Canvas
    Gunakan komponen renderer untuk menampilkan halaman web.
    
    ```tsx title="App.tsx"
    import { KubuildRenderer } from '@kubuild/renderer';

    export default function App() {
      return <KubuildRenderer document={doc} />;
    }
    ```
  </Step>
</Steps>

## 4. Callouts & Information Banners

Fumadocs Callout menyediakan notifikasi visual yang menonjol untuk catatan penting:

<Callout type="info" title="Portable Document Format">
  Dokumen KUBUILD disimpan dalam format `.stora` yang bebas dari ketergantungan runtime browser maupun server database tertentu.
</Callout>

<Callout type="warn" title="Zero UI Dependencies on Core">
  Pastikan `@kubuild/core` tidak mengimpor modul React atau DOM browser agar dapat dieksekusi di Node.js, Cloudflare Workers, dan Deno.
</Callout>
